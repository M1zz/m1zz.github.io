Personvernerklæring

Botaejwo · Gjelder fra 16. oktober 2026

Kort fortalt: Botaejwo har ingen kontoer, og utvikleren driver ingen server som lagrer bildene dine. Bildene går fra avsenderens iPhone til mottakerens iPhone. Utvikleren verken lagrer eller ser på dem.

1. Opplysninger vi samler inn

Botaejwo samler ikke inn navn, e-postadresser, telefonnumre eller kontoopplysninger. Det finnes ingen registrering eller innlogging.

De eneste opplysningene appen behandler, står oppført nedenfor, og de blir værende på brukernes enheter. I tillegg sender appen anonym bruksstatistikk slik at vi kan se om den fungerer som den skal (se punkt 4).

  • Bilder og videoer: bare det avsenderen selv velger. Opplysninger i filene, for eksempel når og hvor de ble tatt, følger med og lagres uendret i mottakerens bildebibliotek.
  • Avsenderens navn: valgfritt. Det brukes bare til å vise mottakeren hvem som sendte hvert bilde, og lagres på mottakerens enhet. Det lagres også på avsenderens enhet, så vedkommende slipper å skrive det inn på nytt.
  • Navn på arrangementer og antall mottatte elementer: lagres bare på mottakerens enhet.

2. Slik sendes bildene

  • På samme Wi-Fi: avsenderens iPhone kobler seg direkte til mottakerens iPhone. Det er ingen server imellom.
  • Når direkte tilkobling ikke er mulig: filene og tilhørende opplysninger krypteres på enheten, legges en kort stund i Apples offentlige iCloud-database (CloudKit) og hentes deretter av mottakeren. Nøkkelen som låser dem opp, finnes bare i QR-koden, så ingen andre enn den som skannet koden og mottakeren kan se innholdet, heller ikke utvikleren. Hvert element slettes så snart det har kommet inn i mottakerens bildebibliotek.
  • Utvikleren driver ingen egen server.

3. Tillatelser på enheten

  • Bilder (mottaker): trengs for å legge mottatte bilder inn i Bilder-appen og opprette albumet for arrangementet.
  • Lokalt nettverk: trengs for å koble til den andre iPhonen på samme Wi-Fi.
  • Avsendere trenger ikke å gi tilgang til bildene sine. Appen bruker Apples bildevelger, så bare det de selv velger, deles med appen.

4. Deling og eksterne tjenester

  • Vi deler ikke personopplysninger med tredjeparter.
  • Vi bruker ikke reklame-SDK-er, analyseverktøy fra tredjeparter eller sporingsteknologi.
  • Anonym bruksstatistikk: for å finne ut hvor mange enheter som bruker appen og for å rette feil, sender appen følgende til Apples iCloud (CloudKit): en tilfeldig ID som opprettes ved installering (ikke knyttet til deg, din Apple-ID, enheten din eller andre apper; den endres hvis du installerer appen på nytt), appversjon, iOS-versjon, region- og språkinnstilling, hvor mange ganger og hvilke dager appen ble åpnet, installeringsdato samt rapporter om krasj og heng (enhetstype og tekniske detaljer). Navn, kontaktopplysninger, posisjon og bilder er ikke med, og bare utvikleren leser dataene. De sendes bare når du er logget på iCloud.
  • Når bilder går via iCloud, brukes Apples infrastruktur, og bildene er kryptert hele veien.

5. Lagring og sletting

  • Mottatte bilder blir liggende i mottakerens bildebibliotek og kan slettes der når som helst.
  • Opplysninger om arrangementet fjernes når arrangementet slettes i appen, eller når appen slettes.
  • Elementer som går via iCloud, slettes så snart mottakeren har hentet dem.

6. Barns personvern

Botaejwo samler ikke inn personopplysninger fra noen, heller ikke fra barn.

7. Verdt å merke seg

Bilder kan inneholde stedet der de ble tatt. Hvis du ikke vil dele det, slår du av posisjon under Valg i bildevelgeren før du sender.

8. Endringer i denne erklæringen

Eventuelle endringer i denne erklæringen publiseres på denne siden. Vesentlige endringer nevnes også i appens oppdateringsnotater.
